## 环境与操作注意

以下为上一份记录之外的补充：

- **本机跑 panel 的 `make ci`**：
  - 需要 `GOTOOLCHAIN=go1.27.1`、`PANEL_REQUIRE_DB=1`，PATH 中包含 `~/go/bin`；
  - 需要 `PLAYWRIGHT_BROWSERS_PATH=~/.cache/ms-playwright`（浏览器已装）。不设时 e2e 目标会执行 `playwright install --with-deps`，可能抢不到 apt 锁而失败；
  - 不要设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`，`/opt/pw-browsers` 只在云端环境存在。
- **新增 `make e2e-admin`**：真实控制面加 Mailpit，用 `panel admin create --password-stdin` 种入超级管理员，运行 `web/e2e/real/m1-02*`。
- **打 tag**：创建 release 时 Target 必须选 `main` 的最新合并提交。v0.6.1 曾误指 v0.6.0 的提交，已删除重建；Go 模块代理已核对，没有缓存错误版本。
- **多人同改 panel**：前后端并行时，前端使用独立 worktree；最后由 lead 合并两条分支，在合并结果上跑完整 `make ci`。
- **工作方式**：负责人要求主会话担任 lead，子代理先出方案、与 lead 辩论再动手，并用简洁英文回报；lead 只向负责人汇报重要事项。
