# M1-03 规格缺口评审（2026-09-27）

背景：M1-03（设备与凭据）开工前，`panel-backend` 提出计划与缺口 a–g，`spec-owner` 对照 spec/10 AUTH-13–AUTH-16、AUTH-22、AUTH-23，spec/11 ACS-01、BIL-13、BIL-15，spec/23 EXP-06，spec/30 API-04、API-11 与客户端契约逐条核对并补充遗漏项，负责人裁定。规格修改见本仓库同一提交，契约修改见 panel-spec v0.9.0（语义变更，按 ENG-04 升小版本）。

## 裁定

| 编号 | 问题 | 裁定 | 落点 |
|---|---|---|---|
| a | ACS-01 允许免费套餐权益（`active`、`tier` 0）访问节点，而 EXP-06 与 `CredentialStatus` 把“免费账号”（含免费套餐持有者）一律视为无凭据 | 免费套餐权益是真实的访问权：在免费套餐的设备上限内下发凭据，导出配置含其可访问的节点。`entitlement_inactive` 与 EXP-06 收窄为“没有权益，或权益为 `over_quota`、`suspended`”；`free_device_limit` 只在没有任何权益时使用，只用于显示。权益状态优先：已有凭据但权益不是 `active` 时为 `entitlement_inactive`，不吊销，`credential` 为 null。免费套餐权益有流量周期（`getUsage.cycle` 只在没有当前权益时为 null）；`Subscription-Userinfo` 在权益没有到期时间时省略 `expire` | spec/10 AUTH-14、spec/11 ACS-01、spec/23 EXP-06、spec/30；契约 `CredentialStatus`、`getMyConfiguration`、`exportConfiguration`、`getUsage`、`UsageUserinfoHeader` |
| b | 验收“设备上限拒绝”的含义；409 `device_limit_reached` 无接口使用 | 验收以登录响应的 `credential_status=device_limit_reached` 表达；409 保留（CONV-14 不删除） | backlog M1-03；AUTH-14 |
| c | 名额计数 | 占用名额的是持有未吊销凭据的非 web 设备 | AUTH-14 |
| 分配 | 按 `last_seen_at` 全量重排会让移除无关设备或刷新令牌挤掉持有凭据的设备 | 单一的单调分配过程：持有数不超过上限时只填空位（无凭据设备按 `last_seen_at` 从近到远），超过上限时才按 `last_seen_at` 保留、其余吊销；不因权益不是 `active` 而吊销（BIL-13 由节点侧移除）；不涉及共用凭据；登录、移除设备、权益变化共用，在账号行锁内执行 | AUTH-14 |
| d | 导出令牌何时建立、链接地址 | 账号创建时与共用凭据同一事务生成，缺失时（AUTH-22 重置后）读取或重置时补建（backfill on rotate）；32 字节随机值 base64url；地址为 API-11 的主地址加 `/v1/configurations/<令牌>`；`created_at` 取 `rotated_at` | AUTH-16；契约 `ExportLink` |
| e | 设备的 IP 前缀与活跃时间 | IP 前缀取该设备最近的会话；刷新时以注入的时钟更新 `last_seen_at`（CONV-27，排序依赖它） | 实现 |
| f | 移除设备 | 吊销该设备全部会话与凭据；web 设备可移除；移除当前设备等同登出，当前 web 设备同时以 `Set-Cookie` 清除认证 Cookie；不需要重新验证；他人设备 404（CONV-15） | AUTH-15 |
| g | 客户端操作是否审计 | 不审计（CON-09 只覆盖管理接口） | — |
| 1 | 重置导入链接 | 不接受 `Idempotency-Key`（CONV-12）；适用 API-04 已认证写接口限流；共用凭据轮换沿用现有 `RotateSharedCredential`（与 AUTH-22 相同）；返回 401 前不写库 | AUTH-16 |
| 2 | 响应缓存与日志 | 读取与重置都带 `Cache-Control: private, no-store`；不记录链接与令牌 | AUTH-16 |
| 3 | 与 AUTH-22 重置的关系 | 分配过程只处理设备凭据，测试断言不触及共用凭据 | AUTH-14 |
| 4 | 并发 | 移除设备与分配过程先取账号行锁，与登录一致 | AUTH-14 |
| 5 | 旧有 36 字符凭据 | 读取时兼容 16 字节与 36 字符两种形式，不设一次性任务；`COMMENT ON COLUMN` 迁移 | backlog M1-03 |

## 范围

`getMyConfiguration` 与 `exportConfiguration` 留在 M2-07（需要节点、入站与 EXP-04 的 ETag）。
