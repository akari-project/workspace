# ADR 0013：控制面优先

- 状态：已接受
- 日期：2026-09

## 背景
项目希望优先开发控制面，包括用户中心与管理后台两个前端。Agent 基于 Xboard-Node fork，内核集成风险已大幅降低。

## 决定
- 里程碑顺序：M0 脚手架 → M1 控制面核心与两端前端 → M2 节点编排与计量（模拟 Agent）→ M3 Agent 改造与 v0.1 → M4 运营完善 → M5 可扩展。
- 契约先行：节点协议与客户端、管理接口在 M0 定稿到可开发程度。
- 前端用 OpenAPI 生成的 Mock 服务开发，不等后端。
- 模拟 Agent 完整实现节点协议，作为 M2 联调对象与长期测试工具。
- M0 仍需完成 Xboard-Node 审计，确保 Agent 改造的风险在节点协议冻结前暴露。

## 影响
- 首个可部署版本（v0.1）在 M3 结束，比原计划晚，但控制面在此之前已可完整演示。
- 模拟 Agent 与真实 Agent 必须共用同一套协议一致性测试，避免行为偏差。
