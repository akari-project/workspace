# ADR 0016：前端嵌入控制面二进制

- 状态：已接受
- 日期：2026-09

## 背景
自托管用户希望部署尽量简单；用户中心与管理后台都是纯静态单页应用。

## 决定
- 两个前端的构建产物通过 Go `embed` 编译进 `panel` 二进制，按 Host 或路径前缀分别提供。
- 服务端在返回 `index.html` 时注入运行时配置（站点名称、接口地址、源代码链接、CSP nonce），同一产物适用于所有部署。
- 带哈希的资源长期缓存，`index.html` 不缓存；构建时预压缩。
- 提供 `noui` build tag 构建不含前端的二进制。

## 影响
- 发布物只有一个控制面二进制（外加容器镜像），升级前后端版本天然一致。
- 构建依赖 Node 与 pnpm；CI 校验嵌入产物与源码同一提交。
- 前端开发时使用 Vite 开发服务器，不依赖嵌入产物。
