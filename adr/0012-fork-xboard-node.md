# ADR 0012：node-agent 从 Xboard-Node fork，并改为本项目协议

- 状态：已接受
- 日期：2026-09

## 背景
自行开发 Agent 需要解决双内核共存、进程内增删用户、按用户计量、七种协议、证书与安装等问题，这些 Xboard-Node 已经实现。但它与控制面的通信使用 Xboard 的节点接口，鉴权为面板全局 API Key，内核在本地配置，缺少流量上报 WAL、配额租约与会话加密。

备选方案：（a）自行开发；（b）不修改 Xboard-Node，控制面实现 Xboard 兼容接口；（c）fork 并替换通信层。

## 决定
采用（c）：一开始就 fork Xboard-Node 到本组织，保留内核集成、协议、证书、路由、部署模式与安装工具，替换与控制面的通信层为 spec/20 的协议，新增接入令牌、控制面选内核、WAL、配额租约与能力上报。

## 影响
- 省去自行实现内核集成的主要工作量与风险；M0-04 改为代码审计。
- 与上游分叉：新代码放在新包，原有包改动登记在 UPSTREAM.md，每月挑选合入上游的内核相关修复。
- 许可证：原有文件保留 MPL-2.0 声明，新文件为 GPL-3.0-or-later，二进制整体按 GPL 分发；NOTICE 列明来源。
- 依赖 Xboard-Node 作者的内核 fork：复制到本组织并锁定提交，优先合入其更新，必要时自行 rebase。
