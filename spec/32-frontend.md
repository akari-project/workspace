# 32 前端

适用范围：`panel/web`（pnpm workspace：`portal`、`admin`、`ui`、`sdk`）。

## 32.1 通用要求

- **UI-01** 只通过 `@panel/sdk`（由 OpenAPI 生成）调用接口，不手写请求。后端未完成时用 `pnpm mock`（Prism 按 OpenAPI 与示例启动）开发。
- **UI-02** 每个数据视图有加载、空、错误三种状态；错误按 `code` 显示本地化文案，并显示 `request_id`。
- **UI-03** 危险操作二次确认并展示影响范围（例如“将影响 312 名用户”）。
- **UI-04** 文案全部走 i18next，至少 zh-CN 与 en；日期、金额、流量按用户语言与时区格式化。金额与流量只做显示格式化，前端不计算折算。
- **UI-05** 深浅色主题；键盘可操作；表单错误与字段关联；对比度满足 WCAG AA。用户中心移动端优先，管理后台桌面端优先。
- **UI-06** 构建产物嵌入控制面二进制（spec/40）：资源使用相对路径；运行时配置从服务端注入的 `window.__PANEL_CONFIG__` 读取，不在构建时写死域名。
- **UI-07** 页脚显示“源代码”链接（spec/01 ARC-04）。
